# Canadian driving schools

Each row is a driving school named on Ontario's open government-approved
driving school list, plus a smaller set from OpenStreetMap in Quebec. A website
is stored only when it is the school's own site and that page contains the
school name. The same school website may appear in more than one city when the
official list names that school in those cities. Directory sites and social
profiles are not stored as the school website.

A car school is category B. No lesson price is stored. Nothing here is a
verified permit, and DriveLinkUp does not book the lesson.

Rebuild with `python3 scripts/americas-schools/collect.py`.
