# United States driving schools

Each row is a driving school whose own website and city are on the OpenStreetMap state extract from Geofabrik. Directory sites and social profiles are not stored as the school website. A school with no city on the map point is not listed.

A car school is category B. A truck or bus category is stored only when that point's name, `driving_school` tag, or a multi-letter licence class says so. A bare US class C or D is an ordinary car class, not a bus. Motorcycle is stored only when the name says motorcycle. A car school is not marked as heavy. No lesson price is stored. Nothing here is a verified permit, and DriveLinkUp does not book the lesson.

The state on the row is the address state, or the state whose map tile contained the point when the address has no state. Cities are listed on that state's page. The country page links the states.
