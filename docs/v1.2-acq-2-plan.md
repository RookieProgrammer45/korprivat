# ACQ-2 plan — Lead dashboard

**Authority:** specs/09 §13 ACQ-2 and SC-24.  
**Status:** pull request open, not merged — [#37](https://github.com/RookieProgrammer45/korprivat/pull/37) on `feat/acq-2-lead-dashboard`.  
**Flag:** `LEAD_DASHBOARD` defaults off. While off, the school dashboard does not render the panel and the lead routes respond 404.

## What this phase does

- A verified school representative can see the count of historical offering requests for that listing.
- A zero-scope listing shows no booking surface and does not collect new inquiries.
- A prompt for inquiry collection appears only when historical inquiries already exist.
- Converting a lead runs the booking permission check and creates neither a booking nor an authorization scope.

## Out of this phase

Category offering publication, outreach, and invented view or conversion metrics. There is no stored page-view counter, so the dashboard does not display one.
