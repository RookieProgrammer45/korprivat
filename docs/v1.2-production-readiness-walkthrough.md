## Method

The rehearsal suite resets `process.env.<FLAG>` in `beforeEach`, so a green Vitest run is not this proof. This walkthrough set each flag to `1` in a dedicated Node process, wrote synthetic rows on the **staging** database, and called the same policy/store functions the routes use (`appendAuthorizationEvent` / `planAuthorizationAppend`, claim/mediated/category/lead/concierge/inbox/certification/alerting).

It was **not** a logged-in browser session. Route wrappers that require better-auth cookies were not HTTP-posted. Where a UI is missing, that is recorded as BLOCKED.

Identity route used (collection plan §0 / specs/09 §8): **evidence-ref + admin/manual review**. e-ID broker access is still `[EXTERNAL]` and was not assumed. Didit learner KYC is a different path and was not used as a grant.
