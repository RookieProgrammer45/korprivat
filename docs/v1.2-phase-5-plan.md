# Phase 5 plan — Certification and admin tooling

**Authority:** specs/09 §8 and §13 Phase 5. Acceptance: SC-8.  
**Status:** merged in [#33](https://github.com/RookieProgrammer45/korprivat/pull/33).  
**Flag:** `CERTIFICATION_ENFORCEMENT` defaults off. While off, native booking does not read certification rows.

## What this phase does

- Partner and certification records. `prodEnabled` is stored per capability.
- Availability, content, and event production enablement require milestone 3 evidence that is not a mock.
- Transactional booking and atomic reschedule require milestone 5 evidence from a vendor environment. Reschedule also requires the atomic-swap test.
- Payment collection stays off. The payment-provider decision is still external.
- A connector instant-booking attempt is refused when transactional booking is not enabled. The native slot path is unchanged.
- Admin list at `/dashboard/admin/partners`. The public partner directory stays hidden until the flag is on, and then lists only `CERTIFIED` partners.
- The school dashboard shows stored production capabilities only while the flag is on. It does not call a connection verified.

## Out of this phase

Vendor-environment test runs, pilot certification, and turning any flag on in production. Those remain Phase 6 and founder actions.
