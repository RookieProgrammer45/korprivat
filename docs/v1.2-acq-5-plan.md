# ACQ-5 plan — Concierge onboarding

**Authority:** specs/09 §13 ACQ-5 and SC-25. Strategy: docs/acquisition-strategy.md §6.  
**Status:** in progress on `feat/acq-5-concierge-tooling`.  
**Flag:** `CONCIERGE_ONBOARDING` defaults off. While off, draft routes respond 404 and do not query.

## What this phase does

- An operator can store a listing draft prefilled from a synthetic public-source fixture. Provenance (source, URL, retrieved time, fields) is stored with the draft.
- The only accepted source is `SYNTHETIC_FIXTURE`. A live register or web scrape is refused.
- The stored draft stays a draft. School approval or correction is required before publication. An admin cannot manufacture that approval.
- School approval, correction, and publication never write policy approval, verification evidence, or authorization scopes.

## Out of this phase

Outreach, bulk publication, real register collection, vendor contact, and production activation.
