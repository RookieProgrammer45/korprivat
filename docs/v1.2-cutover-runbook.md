# Cutover runbook

**Authority:** specs/09 §13 Phase 5 (runbook) and §14.  
**This document does not authorize a cutover.** It lists the order of operations when a founder later authorizes one.

## Preconditions

- Additive schema is already on production. Do not reset the database.
- Inbound webhooks target `https://www.drivelinkup.com`. The apex host 308-redirects and can drop bodies.
- A passing local milestone harness is not vendor evidence. Do not persist it as certification.
- `payment_collection` stays off until the payment-provider decision is recorded.
- Outreach still requires a separate send authorization from `marketing@drivelinkup.com`.

## Pipeline

Every Vercel deploy runs `npx prisma migrate deploy && next build --webpack` (`vercel.json` `buildCommand`, since `b7d2d87` / 2026-10-24). Local `npm run build` is unchanged and does not migrate.

A failed deploy with a Prisma `DATABASE_URL` error means the env var is not available to the **build** environment. Enable it for builds in Vercel settings. `prisma migrate deploy` is idempotent and takes an advisory lock, so concurrent builds are safe.

## Flag order (each one is a separate decision)

Turn on only the flag named in the authorization. Default remains off.

1. `SCHOOL_AUTHZ_ENFORCEMENT` — recorded withdrawals already apply while this is off.
2. `CANCELLATION_POLICY_ENFORCE` — only after at least one listing has an active approved policy. Legacy tiers stay draft.
3. `RELIABLE_PROCESSING` — inbox/outbox writes join the booking transaction.
4. `CONNECTIVITY_API` — partner HMAC routes. Credentials stay in `CONNECTIVITY_PARTNER_SECRETS`.
5. `CERTIFICATION_ENFORCEMENT` — connector instant booking stays refused without milestone 5 vendor-environment evidence.
6. `CLAIM_FUNNEL` / `SCHOOL_MEDIATED_INSTRUCTORS` / `LEAD_DASHBOARD` / `CATEGORY_OFFERINGS` / `CONCIERGE_ONBOARDING` — acquisition surfaces. Real register collection stays blocked.
7. `OPS_ALERTING` — admin snapshot and threshold evaluation. Set threshold env vars only after a measured baseline.

## Rollback

Set the same env var back to unset/`0`. Recorded withdrawals, quarantines, financial history, and authorization events are not deleted by turning a flag off.

## After a flag is on

- Watch `/dashboard/admin/ops-alerts` (requires `OPS_ALERTING`).
- Inbox depth, dead letters, unresolved quarantine, and open late-capture ops tasks are the first signals.
- Do not treat an empty partner directory as a failure. Nothing in this build promotes a partner to `CERTIFIED`.
